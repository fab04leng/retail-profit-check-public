# 试点入门指南：要发送什么资料、如何导出

*给已经同意参加 Retail Profit Check 试点的店主。请在签好试点协议之后交给店主。大多数店主需要 30–60 分钟完成。*

我们需要从您自己的系统导出**四个文件**。您不需要整理或美化文件，直接导出的原始文件最好。如果有些资料很难拿到，先把能拿到的发给我们，并告诉我们，我们会帮您。

---

## 1. 四个文件

**所有文件请用同一个期间：3 到 12 个月**，结束日期尽量接近今天。12 个月最好，因为可以涵盖节日季节。

| # | 文件 | 是否需要 | 每一行是… | 我们会用的栏位 | 常见报表名称 |
|---|---|---|---|---|---|
| 1 | **按项目的销售资料** | 必须 | 收据上的每一项货品（不是每天一行） | 日期、收据号码、货号/SKU、品名、类别、数量、单价、折扣、行总额、分店 | “Receipts by item”“Sales detail”“Transaction details”“Item sales listing” |
| 2 | **产品 / 库存清单** | 必须 | 每一种产品 | 货号/SKU、品名、类别、**单位成本**、**现有库存数量**、最后进货日期（如有） | “Item list”“Stock balance”“Inventory valuation”“Stock item listing” |
| 3 | **供应商发票** | 建议提供 | 发票的每一行（最好）或每一张发票 | 供应商、发票号码、发票日期、货号、项目说明、数量、单价、总额、**到期日** | “Purchase invoice listing (detail)”“Supplier invoice listing”“Goods received” |
| 4 | **付给供应商的款项** | 可选 | 每一笔付款 | 付款日期、供应商、金额、参考（所付的发票号码） | “Payment listing”“A/P payment listing”“Supplier payment” |

请留意：
- **没有文件 3**，我们就无法检查供应商发票（重复发票、涨价）。**没有文件 4**，我们就无法检查多付款项或找不到发票的付款，而现金展望会假设开始日期之前到期的发票都已付清。
- **每张发票只有一行**（没有货品明细）的供应商发票，仍然可以用来检查重复发票和付款，但不能检查供应商涨价。
- **产品/库存清单最好在销售期间的最后一天导出**，最好是刚盘点完之后。如果最近没有盘点，系统里的数量往往不准，会影响死货的结果。
- **如果方便，请把销售期间开始前 1–2 个月的供应商发票也一起发来。** 否则在期间初期支付旧发票的款项，会显示为“找不到对应发票的付款”。
- **有几间分店：** 最好是一个包含所有分店、并有“分店”栏的文件。每间分店各一个文件也可以，只要文件名写明是哪一间分店。
- **文件类型：** Excel（`.xlsx`）或 CSV。Excel 文件只会读取**第一个工作表**。**不要**发 PDF、照片或扫描件。旧的 `.xls` 文件：请用 Excel 打开，再选 *另存为 → Excel 工作簿（.xlsx）*。
- 栏位名称用英文、马来文或中文都可以。文件顶部的标题行、底部的“合计”行也没有关系。

## 2. 常用系统的导出方法

> ⚠️ **未经验证。** 以下系统我们**还没有用真实导出的文件测试过**。步骤来自软件商的公开说明页面（能找到的话），或是我们根据常见菜单名称的推测。不同版本和配套的菜单会不一样。如果找不到报表，**请把您的“报表”菜单截图发给我们**（画面里不要有顾客资料），我们会一步一步教您；或者请您的系统供应商帮忙导出“按项目的销售 / 库存结余 / 进货发票清单，导出成 Excel”。

### Loyverse POS（在网页浏览器打开 Back Office）— 未经验证
- **销售（文件 1）：** *Reports → Receipts*。设定日期范围，然后按 *Export*。如果有选项，请选择**按项目**导出（每一项货品一行），而不是每张收据一行。Loyverse 的说明页面提到这两种导出。
- **产品（文件 2）：** *Items → Item list → Export*。文件里应该有 **Cost**（成本）和 **In stock**（库存）。只有开启了库存追踪的货品才会有 In stock。
- **供应商发票（文件 3）：** Loyverse 是 POS 系统，不一定有供应商发票。如果您有用它的采购单（*Inventory management → Purchase orders*），就导出那些。否则请从会计系统导出，或用 Excel 清单（见“其他系统”）。
- **付款（文件 4）：** 通常不在 Loyverse 里。请从会计系统导出，或用 Excel 清单。

### StoreHub BackOffice — 未经验证
- **销售（文件 1）：** 在 *Reports* 里找**有货品明细的交易或销售报表**，设定日期范围，然后 *Export*（CSV）。必须是每卖出一项货品一行，不是每天一行。
- **产品（文件 2）：** 在 *Products* 或 *Inventory* 里找可以导出每种产品**成本**和**库存数量**的功能（有几间分店的话，按分店）。
- **供应商发票（文件 3）：** StoreHub 的说明页面提到库存导出包含 *Date、Reference Number、Supplier、Outlet* 和货品明细（例如来自采购单或进货）。请导出该期间的资料。如果您的供应商发票记在会计系统里，就请从会计系统导出。
- **付款（文件 4）：** 从会计系统或银行导出（见“其他系统”）。

### AutoCount Accounting — 未经验证
AutoCount 大部分清单报表都可以在报表表格里用 **Export → Excel** 导出。有“明细”（detail）清单的话，请选明细。
- **销售（文件 1）：** 如果您用 AutoCount POS，就导出按项目的销售或 POS **明细**清单；否则从您的 POS 系统导出。
- **产品（文件 2）：** *Stock → Stock Balance*（或 *Stock Item Listing*），要有 **Balance Qty** 和**成本**栏，日期设为期间最后一天 → 导出 Excel。
- **供应商发票（文件 3）：** *Purchase → Purchase Invoice*，然后选该期间的**明细清单** → 导出 Excel。如果报表有以下栏位，请包括：**Creditor Name、Doc. No.、Doc. Date、Item Code、Description、Qty、Unit Price、SubTotal 和 Due Date**。
- **付款（文件 4）：** 该期间的 *A/P → Payment* 清单 → 导出 Excel，如果有 **knock-off**（所冲销的发票号码）栏，请一起导出。

### SQL Account — 未经验证
- **销售（文件 1）：** 从您的 POS 系统导出（见“其他系统”），除非您在 SQL Account 里按项目记录销售。
- **产品（文件 2）：** *Stock → Stock Balance*（或库存估值报表），日期设为期间最后一天 → 导出 Excel，要有数量和成本。
- **供应商发票（文件 3）：** 该期间的 *Supplier → Supplier Invoice*（或 *Purchase → Purchase Invoice*）**明细**清单 → 导出 Excel。单据号码、单据日期、供应商代号和名称、货号、项目说明、数量、单价、金额和到期日都有用。
- **付款（文件 4）：** 该期间的 *Supplier → Supplier Payment* 清单 → 导出 Excel，说明或参考栏要能看出付了哪些发票。

### 其他系统，或用 Excel、纸本记录
- 在您的 POS 或会计系统里，找第 1 部分表格中的报表名称，然后按 *Export* 或 *Excel*。如果某个报表只能打印或存成 PDF，**请先告诉我们，不要重新打字**。通常在别的地方会有导出选项。
- **供应商发票是纸本或 Excel：** 一份简单的 Excel 清单就可以，每张发票一行（供应商、发票号码、发票日期、总额、到期日）。我们可以发给您空白模板。
- **从银行导出付款：** 网上银行月结单导出成 Excel 或 CSV 也可以，只要说明栏看得出供应商和发票号码。发送前**请删除所有不是付给供应商的行和栏**（见第 3 部分）。

## 3. 发送前请删除个人资料

我们不需要您的顾客或员工的任何个人资料。发送前**请删除以下栏位**（或整个工作表）：

- 顾客**姓名**、**电话号码**、**电邮**、**地址**、**身份证 / MyKad / 护照号码**
- **会员或积分卡号码**、顾客编号或顾客代号（如果能对应到某个人）
- **员工或收银员姓名**（不需要，请删除该栏）
- **银行户口号码**，以及任何看起来像**信用卡号码**的资料
- 收银时手打的**备注或说明**（常常包含姓名或电话）

**请保留**第 1 部分列出的栏位，包括供应商名称（我们需要用它来对应发票和付款）。

**在 Excel 里怎么做：**
1. 在导出文件的**副本**上操作，保留原文件。
2. 在栏的字母（例如 **C**）上按右键 → **删除**。每个要删除的栏都照做。
3. **取消所有隐藏：** 在任何栏的字母上按右键 → *取消隐藏*，并检查有没有隐藏的工作表（在工作表标签上按右键 → *取消隐藏*）。隐藏的栏和工作表仍然会被发送出去。
4. **删除不需要发送的其他工作表。** 我们只用第一个工作表，但其他工作表还是会一起发送出去。
5. 存成 `.xlsx`（或 `.csv`）。

如果我们发现您不小心发来了个人资料，我们会删除那些栏位，并告诉您。

**发送文件：** 请用试点协议中约定的方式（例如设了密码的文件，或加密的 USB）。**密码请分开发送**，例如打电话或发短信告诉我们，不要和文件放在同一个讯息里。请不要把文件发到群组里。

## 4. 清单：要发送什么

- [ ] **按项目的销售资料**，从 ______ 到 ______（3–12 个月），包括所有分店
- [ ] **产品 / 库存清单**，有单位成本和现有库存数量，导出日期 ______（尽量接近最后的销售日期）
- [ ] 同一期间的**供应商发票**（方便的话加上之前 1–2 个月），有到期日的话请包括
- [ ] *（可选）* 从期间开始到今天的**供应商付款**
- [ ] 已删除个人资料栏位（顾客、员工、银行户口、备注）；已检查隐藏的栏位和其他工作表
- [ ] 文件是 `.xlsx` 或 `.csv`（不是 PDF 或照片），文件名清楚，例如 `sales_2026-01_to_2026-06.xlsx`
- [ ] 附上一段简短说明：
  - 每个文件来自哪个系统，以及您有哪些分店
  - 期间内有没有特别的事情（装修、停业、盘点、大型促销、换供应商）
  - 为了 8 周现金展望：**今天的银行现金**、**透支额度**（如有），以及**每月固定开销**（租金、薪水、EPF/SOCSO、水电、还贷）和每项在每月几号支付
- [ ] 已用约定的安全方式发送，密码分开发送

## 5. 接下来会怎样

1. 我们会检查每个文件都能打开、栏位都认得出来；如果有缺少或不清楚的地方，会告诉您。
2. 我们进行检查，然后由负责审阅的会计师把每项发现标为“已确认”“没有问题”或“需要更多资料”。有些发现需要您回答，例如“这笔是订金吗？”
3. 按照试点协议的时间安排，进行结果会议并提供书面报告（资料齐全后大约 2 周）。
4. 您的文件会在您要求时删除，最迟按照试点协议的规定删除，并以书面确认。

**提醒：** 结果是需要您和您的会计师对照单据核查的可能问题。这不是经审计的账目或税务建议，我们也不能保证会有任何特定的发现或节省。
