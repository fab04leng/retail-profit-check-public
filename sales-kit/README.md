# Sales kit: Retail Profit Check

Materials for validating an accountant-backed finance service for Malaysian retail SMEs. **Demand is not proven yet.** The goal of this kit is **10 owner interviews and 2 paid pilots (RM300) on real data.**

Each file comes in English (`.en.md` / `.md`) and Simplified Chinese (`.zh.md`).

| # | File | Use it for | Who uses it |
|---|---|---|---|
| 1 | `01-offer.en.md` / `01-offer.zh.md` | One-page offer to print or send after a first chat | Everyone |
| 2 | `02-interview-script.en.md` / `.zh.md` | 15-minute past-behaviour interview, note template, commitment signals | Interviewer + note-taker |
| 3 | `03-whatsapp-outreach.en.md` / `.zh.md` | Short WhatsApp messages from the accountant to his contacts (English file includes an optional Malay version) | The accountant |

## Suggested flow

1. **Reach out:** the accountant sends message 1 from `03` to warm contacts (5–10 a day).
2. **Interview (15 min):** use `02`. Don't pitch until the end, and fill in the note template within the hour.
3. **Demo (5 min), if the owner is interested:** use `DEMO_SCRIPT`. Always say the numbers come from a fictional shop.
4. **Pilot ask:** leave `01-offer` behind and handle concerns with `04`.
5. **Agreement:** only once a lawyer has reviewed `05`.
6. **Onboarding:** after signing, send the owner `06` and offer a short call to help with the exports.
7. **Track:** interviews done / pilots agreed / data received / introductions. Count only real commitments (time, money, data, introductions), not compliments.

## Rules for everyone using this kit

- The tool is an **analysis aid**. It is **not audited accounts, not tax advice, and never a replacement for an accountant**. Findings need review by a qualified accountant.
- **No AI runs on owner data.** The checks are readable rules an accountant can check and change, and every finding shows its evidence rows.
- Use "possible duplicate", "may", "needs review" and "estimate". **Never promise savings** or present estimates as facts.
- Monthly pricing is **being tested** (around RM300–RM800/month depending on outlets). It is not a fixed price.
- **Privacy:** in the demo, data stays on the computer in the browser. In the pilot, files go on an encrypted laptop, are never shared, and are deleted on request (PDPA 2010).
- Don't put real business names, customer data or other people's personal details into this kit or the demo.
